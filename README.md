# Платформа для проведения ИТ-баттлов

Проект выполнен в рамках технического задания. Представляет собой веб-платформу для проведения соревнований по программированию с возможностью сбора решений и зрительского голосования в реальном времени (с использованием HTMX).

## Требования
* Python 3.10+
* Git

## Инструкция по запуску

1. **Клонируйте репозиторий:**

   git clone https://github.com/Lileck/it_battles.git 
   cd it_battles
2. Создание и активация виртуального окружения
Windows:
bash
python -m venv venv
venv\Scripts\activate
macOS/Linux:

bash
python3 -m venv venv
source venv/bin/activate

3. Установка зависимостей
Все необходимые библиотеки зафиксированы в requirements.txt:
bash
pip install -r requirements.txt

4. Применение миграций
Создайте структуру базы данных:
bash
python manage.py migrate

5. Создание суперпользователя (для доступа в админку)
bash
python manage.py createsuperuser
(Введите логин, email можно пропустить, придумайте пароль)

6. Заполнение базы тестовыми данными 
Специально для быстрой демонстрации реализована команда, которая создает событие, 4 команды, примеры решений и голоса:

bash
python manage.py seed_data
После выполнения команда выведет в консоль ID созданного события (например, ID: 1). Запомните его, он понадобится для проверки.

7. Запуск сервера разработки
bash
python manage.py runserver

Как проверить работоспособность (Сценарии)
После запуска сервера откройте браузер и проверьте следующие страницы (замените 1 на ID вашего события, если команда seed_data создала его под другим номером):

Админка ведущего: http://127.0.0.1:8000/admin/

Здесь можно создать новое событие, изменить его статус (Ожидание, Прием решений, Голосование, Завершено), управлять командами.

Экран ведущего (Проектор): http://127.0.0.1:8000/battle/ввести id/host/

Отображает присланные решения с подсветкой синтаксиса (Pygments).

Автоматически обновляет счетчик голосов каждые 3 секунды (HTMX polling).

Генерирует QR-код для подключения зрителей.

Экран участника (Отправка решения): http://127.0.0.1:8000/battle/ввести id /submit/

Форма доступна только когда статус события — «Приём решений».

Позволяет выбрать команду из списка и вставить код.

При повторной отправке решение перезаписывается.

Экран зрителя (Голосование): http://127.0.0.1:8000/battle/ввести id/vote/

Доступен только в статусе «Голосование».

Карточки команд с кнопкой «Голосовать».

При нажатии кнопка меняется на плашку «Голос учтен» без перезагрузки страницы (HTMX).

Реализована защита от накруток: с одного устройства можно проголосовать только один раз за всё событие.

Проверка QR-кода на реальном смартфоне
По умолчанию сервер запускается на 127.0.0.1 (доступен только на компьютере). Чтобы проверить QR-код с телефона:

Запустите сервер с привязкой ко всем интерфейсам: python manage.py runserver 0.0.0.0:8000

Узнайте IP-адрес вашего компьютера в локальной сети (например, 192.168.0.111).

В файле config/settings.py добавьте ваш IP в ALLOWED_HOSTS: ALLOWED_HOSTS = ['127.0.0.1', '192.168.0.111']

Откройте экран ведущего на компьютере по IP: http://192.168.0.111:8000/battle/4/host/

Наведите камеру телефона на QR-код (телефон должен быть подключен к той же Wi-Fi сети).
